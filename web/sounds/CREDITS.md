# Sound credits

These sound effects are the original **Stick Soldiers II** sounds (2003, Whitespace Unlimited: Tim Cowley, Dylan Allison, Andrew Vehlies). They were taken from the [Stick Soldiers Python (SSPy)](https://sourceforge.net/projects/sspy/) fan project on SourceForge, which redistributed them unchanged. Every file is byte-identical to the one in the original game.

SSPy's GPLv2 licence covers its own code. It does not cover these sounds, which still belong to Whitespace Unlimited.

The only change made here is converting each file to mono 22 kHz 16-bit WAV.
